# ربط العملاء بقوقل شيت

كل صفحات الموقع (صفحة إضافة العميل للموظفين، الموقع الرئيسي، صفحات الهبوط، الإعلانات، لوحة الإدارة) ترسل العميل عبر `clients.js` إلى سكربت قوقل، والسكربت يوزّعه على التبويبات حسب نوع الإدخال:

| نوع الإدخال | التبويب في الشيت |
|---|---|
| عميل اتصال (صفحة تسجيل عميل جديد للموظفين) | تسجيل عميل جديد |
| رغبة استثمار | رغبة استثمار |
| عرض عقار (طلب تسويق) | طلب تسويق |
| طلب شراء | طلبات الشراء |
| تسجيل اهتمام (الموقع، صفحات الهبوط، الإعلانات) | تسجيل الاهتمام |
| طلبات (من قسم الطلبات أو طلب شراء) | الطلبات |
| **كل العملاء** | العملاء قاعدة البيانات |
| أي عميل مرتبط بعرض (اهتمام من صفحة هبوط العرض أو من الموقع، أو موظف اختار العرض) | تبويب العرض نفسه: «عرض - اسم العرض» |
| نشر عرض في الموقع | يُنشأ تبويب العرض + صف في تبويب «العروض» (رابط صفحة الهبوط، عدد المهتمين، رابط التبويب) |

الأعمدة: التاريخ، النوع، الاسم، الجوال، الاهتمام، العرض، الملاحظة، الموظف، المصدر، المعرف.

## التركيب (مرة وحدة)

1. افتح ملف قوقل شيت الخاص بالعملاء، ومنه: **الإضافات ← Apps Script** (Extensions ← Apps Script).
2. احذف الكود الموجود في `Code.gs` والصق محتوى الملف [`Code.gs`](Code.gs) كاملاً، ثم احفظ.
3. اختر الدالة `setupSheets` من القائمة فوق واضغط **تشغيل** (Run). هذي تنشئ كل التبويبات بعناوينها. وافق على الصلاحيات أول مرة.
4. انشر السكربت بتحديث النشر الحالي حتى **يبقى نفس الرابط** المستخدم في الموقع:
   **نشر ← إدارة عمليات النشر ← ✏️ تعديل ← الإصدار: إصدار جديد ← نشر**
   (Deploy ← Manage deployments ← Edit ← Version: New version ← Deploy).
   تأكد أن «من يمكنه الوصول» = **أي شخص** (Anyone).

> إذا سويت «نشر جديد» بدل تعديل النشر الحالي بيطلع رابط جديد، ولازم يتغيّر `SHEETS_URL` في أول ملف `clients.js`.

> إذا كان عندك تبويب قديم بنفس الاسم (مثل «تسجيل الاهتمام») وأعمدته مختلفة، غيّر اسمه (مثلاً «تسجيل الاهتمام - قديم») قبل الخطوة 3، حتى تنشأ نسخة جديدة بالأعمدة الصحيحة.
