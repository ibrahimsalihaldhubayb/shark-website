ربط Google Sheets

أنشئ Google Apps Script وأدخل رابط الـ webhook هنا لإرسال بيانات العملاء تلقائياً عند كل تسجيل.

كيفية الإعداد ←
1. افتح script.google.com وأنشئ مشروعاً جديداً
2. أنشئ Google Sheet واربطه بالسكريبت
3. ألصق الكود التالي في المحرر:
function doPost(e){
  var sheet=SpreadsheetApp.getActive().getActiveSheet();
  var d=JSON.parse(e.postData.contents);
  sheet.appendRow([d.date,d.name,d.phone,d.type,
    d.interest,d.offerTitle||'',d.note||'',d.source||'']);
  return ContentService.createTextOutput('ok');
}
4. انشر → نشر كتطبيق ويب → الوصول: أي شخص
5. انسخ رابط النشر والصقه أدناه
