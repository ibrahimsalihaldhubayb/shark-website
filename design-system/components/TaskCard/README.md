بطاقة المهمة في صفحة «المهام». البطاقة بيضاء دائماً، والحالة تظهر في الشارة فقط، ولا تتلوّن البطاقة كلها.

- **الرأس**: العنوان بخط kufi، وشارة الحالة (جارية `info`، متأخرة `danger`، مكتملة `success`).
- **الوصف**: سطران كحد أقصى بلون `muted`.
- **التواريخ**: تاريخ الإسناد وتاريخ التسليم. إذا تأخرت المهمة يصير تاريخ التسليم بلون `danger`.
- **الملاحظة**: صندوق `warning-soft` يبدأ بكلمة «ملاحظة:».
- **الشريط السفلي**: المسؤول (صورة رمزية + اسم) يميناً، وأزرار التقييم `sh-chip` يساراً (إنجاز، تبرير، تنبيه، تميّز). الزر المختار `aria-pressed="true"`.
- **sh-task-late**: خط `danger` بسماكة 3px على حافة البداية.
- **sh-task-done**: عنوان المهمة بلون `muted`.

المستخدم يوفّر: العنوان، والوصف، والحالة، والمسؤول، وتاريخ الإسناد، وتاريخ التسليم، والملاحظة، وأزرار التقييم المتاحة حسب الحالة ودورها.
