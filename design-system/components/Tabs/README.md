تبويبات مجمّعة للفلترة السريعة ولتبديل طريقة العرض.

- التبويب المختار تعبئته `ink` ونصه `on-ink`، والباقي نصه `muted`.
- أضف `sh-tab-count` لعدد العناصر في كل فلتر.
- في صفحة العروض: «الكل / حصرية / غير حصرية»، وبجانبها «بطاقات / جدول / خريطة».
- في صفحة المهام: «الكل / جارية / متأخرة / مكتملة».

المستخدم يوفّر: العناصر (النص والعدد والأيقونة اختيارياً)، والعنصر المختار، ودالة التغيير. استخدم `role="tablist"` و`aria-selected`.
