صفحة «المهام» في مساحة شارك: لوحة من 3 أعمدة حسب الحالة، بدل البطاقات الملوّنة بالكامل.

- **الهيكل**: `AppShell` والرابط النشط «المهام».
- **رأس الصفحة**: العنوان والوصف وزر «مهمة جديدة».
- **صف الملخص**: 4 بطاقات أرقام (كل المهام، جارية، متأخرة، مكتملة)، وبطاقة نسبة الإنجاز مع شريط تقدم بلون `ink`.
- **شريط الأدوات**: تبويبات الحالة، والبحث، وقائمة الموظفين، وتبديل العرض (لوحة / حسب الموظف).
- **اللوحة**: 3 أعمدة `sh-column` بالترتيب: متأخرة، جارية، مكتملة. داخل كل عمود بطاقات `TaskCard`، والأحدث تسليماً في الأعلى.
- **عرض «حسب الموظف»**: قسم لكل موظف فيه اسمه وعدد مهامه، وتحته شبكة من عمودين من `TaskCard`.
