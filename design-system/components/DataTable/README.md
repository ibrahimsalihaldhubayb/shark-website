جدول البيانات في لوحة التحكم، للعروض والعملاء والحركات المالية.

- رأس الجدول على `surface-raised` بنص `muted` 12px، والصفوف على `surface` يفصل بينها `hairline`.
- الخلية الأولى `sh-table-main`: صورة مصغّرة 48×36 + الاسم + الرمز المرجعي.
- عمود الإجراءات آخر عمود، فيه أزرار أيقونات `sh-iconbtn` فقط. الحذف يكون داخل قائمة «المزيد»، ولا يظهر كزر أحمر في كل صف.
- استخدم `sh-switch` للنشر، والشارات للحالة والنوع.
- لا تكرر الشرطة «—» في الخلايا الفارغة: اترك الخلية فارغة، أو اكتب «عند الطلب» للسعر.

المستخدم يوفّر: الأعمدة، والصفوف، وإجراءات كل صف، ودالة الترتيب.
