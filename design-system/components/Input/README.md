حقول الإدخال: نص، بحث بأيقونة، وقائمة منسدلة، كلها بارتفاع 40px.

- **sh-input** على `surface` بحد `border-strong` وزاوية `radius-sm`. النص التوضيحي بلون `muted`.
- **sh-input-wrap** يضع أيقونة البحث في بداية الحقل (يمين في RTL).
- **sh-field** يجمع العنوان `sh-field-label` والتلميح `sh-field-hint` مع الحقل.
- الأرقام (المساحة، الجوال، السعر) تُكتب `dir="ltr"` بأرقام لاتينية.

المستخدم يوفّر: العنوان، والنص التوضيحي، والقيمة، ورسالة الخطأ إن وجدت (بلون `danger` تحت الحقل).
