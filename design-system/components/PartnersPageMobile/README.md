نفس صفحة «مشاريع الشركاء» ونفس الـHTML، معروضة بعرض جوال 390px: كل التغيير من CSS داخل `@media (max-width: 768px)` في `bundle.css`، فلا يتأثر الويب.

- **الشريط العلوي** `sh-mtopbar` (56px، ثابت أعلى الشاشة): رمز الشعار و«مساحة شارك»، والبحث، والإشعارات، والمستخدم. الشريط العلوي للويب يختفي.
- **الشريط السفلي** `sh-bottomnav` (ثابت أسفل الشاشة): الرئيسية، عروضنا، المهام، المحادثة، القائمة. زر «القائمة» يفتح القائمة الجانبية كاملة (`MobileNav`).
- **الأرقام** تصير صفاً يُسحب أفقياً.
- **البحث** بعرض كامل مع زر «تصفية»، والتبويبات تحته بعرض الشاشة.
- **الجدول** يصير بطاقات: الصورة والاسم والرقم، ثم الشريك، ثم النوع والمدينة، ثم السعر، وفي الأسفل مفتاح النشر وزر «تعديل» و⋯.
- **اللمس**: الأزرار والحقول بارتفاع 44px، والحقول بخط 16px حتى لا يكبّر iPhone الصفحة عند الكتابة، مع هوامش `safe-area` للشاشات ذات الحواف.

القاعدة لكل صفحات المساحة: أي جدول بإضافة `is-stack` و`sh-table-stack` و`data-label` لكل خلية يتحول لبطاقات على الجوال بنفس الطريقة. `sh-cell-main` للخلية الرئيسية، و`sh-cell-wide` لخلية بعرض البطاقة، و`sh-cell-foot` لخلايا أسفل البطاقة، و`sh-cell-nolabel` لإخفاء التسمية.
