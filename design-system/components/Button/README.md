الأزرار في مساحة شارك: زر أساسي واحد في كل صفحة، والباقي ثانوي أو شفاف.

- **sh-btn-primary**: تعبئة `ink` ونص `on-ink`. للإجراء الرئيسي في الصفحة فقط (إضافة عرض، مهمة جديدة، إضافة حركة).
- **sh-btn-secondary**: حد `border-strong`. للإجراءات المساندة (تحديث، روابط الموظفين).
- **sh-btn-ghost**: بلا حد، للإلغاء والإجراءات داخل الصفوف.
- **sh-btn-danger**: نص `danger` بلا تعبئة، وتظهر `danger-soft` عند التحويم. الحذف يطلب تأكيداً دائماً.
- **sh-btn-sm**: ارتفاع 32px داخل الجداول والبطاقات.
- **sh-iconbtn**: زر أيقونة 36px، ولازم يكون معه `aria-label`.

المستخدم يوفّر: النص، والأيقونة اختيارياً (قبل النص)، والحالة `disabled`.
لا تستخدم الذهبي `gold` كخلفية زر: الذهبي مخصص للعروض الحصرية والعنصر النشط.
