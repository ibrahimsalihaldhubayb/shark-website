صفحة «مشاريع الشركاء» في مساحة شارك: مشاريع المطورين الشركاء المعروضة في موقع شارك، بكود واحد للويب والجوال.

- **الهيكل**: `AppShell`، والرابط النشط «مشاريع الشركاء».
- **رأس الصفحة**: العنوان والوصف، وزر «إضافة مشروع» الأساسي (`sh-btn-primary`، أسود لا ذهبي).
- **صف الأرقام** `sh-stats`: المشاريع (بالخط الذهبي)، والمنشورة، والشركاء، والمدن.
- **شريط الأدوات**: تبويبات «الكل / منشورة / مخفية» مع الأعداد، والبحث (اسم المشروع أو الشريك أو الرقم)، وقوائم الشريك والنوع والمدينة (`sh-only-desktop`)، وعلى الجوال زر «تصفية» واحد (`sh-only-mobile`) يفتح نفس القوائم.
- **الجدول** `sh-table sh-table-stack` داخل `sh-table-wrap is-stack`: المشروع (صورة + اسم + رقم PR)، الشريك، النوع (`sh-badge` محايدة)، المدينة، السعر، النشر (`sh-switch` مع كلمة منشور/مخفي)، الإجراءات.
- **السعر**: «من 685,000 ريال» بأرقام لاتينية داخل `<bdi>`. إذا لم يوجد سعر اكتب «السعر عند الطلب» بلون `muted`. لا تعرض قيمة فارغة أو NaN («ليس رقماً ريال» في الصفحة الحالية خطأ).
- **الإجراءات**: زر «تعديل» ثانوي، وزر ⋯ (`sh-menu`) فيه: معاينة في الموقع، نسخ رابط المشروع، حذف المشروع (`sh-menu-item-danger`) مع نافذة تأكيد. لا يظهر زر الحذف أحمر في كل صف.
- كل خلية لها `data-label`؛ على الجوال يتحول كل صف إلى بطاقة تلقائياً (انظر `PartnersPageMobile`).

البيانات في المعاينة أمثلة توضيحية عدا «مخطط الزمردة». المطوّر يوفّر: قائمة المشاريع (الصورة، الاسم، الرقم، الشريك، النوع، المدينة، أقل سعر، حالة النشر)، والأعداد، ودوال التعديل والنشر والحذف.
