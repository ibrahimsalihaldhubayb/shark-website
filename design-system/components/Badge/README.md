شارة صغيرة توضح حالة العنصر أو تصنيفه، وتحتوي كلمة دائماً.

- **sh-badge-exclusive**: تعبئة `gold` ونص `on-gold` مع نجمة. للعروض الحصرية فقط.
- **sh-badge-outline**: للتصنيف المحايد (غير حصري، نوع العقار، نوع الطلب).
- حالات المهام: `sh-badge-info` (جارية)، و`sh-badge-danger` (متأخرة)، و`sh-badge-success` (مكتملة)، و`sh-badge-warning` (تسليم قريب).
- حالات النشر: `sh-badge-success` (منشور)، والشارة الافتراضية (غير منشور).
- أضف `sh-badge-dot` للحالات، ولا تضفها للتصنيفات.

المستخدم يوفّر: النص والنوع. لا تستخدم أكثر من شارتي حالة على نفس العنصر.
